# Golkonda Sanjana — Developer Portfolio

A responsive personal portfolio built with React, Vite, and CSS.

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL Vite prints (usually `http://localhost:5173`).

## Customize
- Add actual profile/social links when ready (currently intentionally omitted).
- Update project details to match final implemented work and add repository links when available.
- Replace the typographic monogram with a photo if desired.

## Build check
Run `npm run build` to produce the production build in `dist/`.
